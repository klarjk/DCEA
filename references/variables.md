# 변수 사전

저자가 정리한 추출 변수와 방향성. 원문 16(초보자를 위한 변수 안내서)이 기둥이고 다른 글의 수치를 병합했다.

**전제**: 모든 항목은 "다른 변수를 모두 고정한 상태"의 단일 변수 효과다. 원문에 정량 임계값은 거의 없다 — 방향성만 쓰고, 수치가 필요하면 사용자 자신의 지난 추출을 기준점으로 삼는다.

계층 표기: `근본` = 향미 총량을 바꿈(처방 대상 아님) / `조절` = 처방 가능. 근거는 `model.md`의 변수 2계층.

> **추출비 표기**: 이 문서 묶음은 일반 표기를 따른다 — **추출비가 높다 = 물이 많다**(1:17이 1:16보다 높다). 원문 01·02만 반대 방향으로 표기하며(07·09·12·14는 일반 표기 — 2026-08 대조), 그 두 글을 **요약·재서술할 때만** 방향을 뒤집는다. **따옴표로 묶은 원문 그대로의 인용은 뒤집지 않는다** — 출처 표기 규칙이 우선한다.

## 결과 지표

| 변수 | 올리면 |
|---|---|
| **농도(TDS)** | 맛·플레이버의 강도와 지속시간 증가. berry·green·citrus 계열이 강해짐. **fermented·sourness·bitterness·astringency·harshness 같은 부정적 느낌도 함께 증가** |
| **수율(EY)** | 산미의 톤이 어두워짐. 단맛이 증가하다가 **어느 지점을 넘으면 쓰고 탄맛으로 바뀜**(비단조). 특정 커피는 floral finish. 떫은맛 가능성도 증가 |

| 변수 | 조작 | 결과 |
|---|---|---|
| **바스켓 타공비율** | 높음 | 저항↓ 추출속도↑ |
| **바스켓 홀 분포** | 중앙 집중 | 중앙 편추출 → **수율↓ · 일관성↑ · 저항↑ · 속도↓**(아래 항목 참조) |
| **바스켓 크기** | 큼 | 베드 높이↑ → 고른 추출 비율↑ → **수율↑** (VST·라마르조꼬처럼 크기에 따라 구멍을 조절하는 바스켓만 해당) |
| **헤드스페이스** | 넓음 | 최대 압력 도달까지 오래 걸림 → 프리인퓨전과 비슷한 효과 → **약배전에 유리** |
| **헤드스페이스** | 좁음 | 압력이 급격히 상승 → **강배전(바디·크레마)에 유리** |
| **프리인퓨전 시간** | 길게 | 균일성·일관성↑, **퍽 저항↓ → 후반 속도↑**, 크레마↓ → 약배전에 유리 |
| **프리인퓨전 유량** | 높게 | 퍽 하단에 촘촘한 벽 형성 → **저항↑ · 크레마↑ · 수율↓** (`brewers/espresso.md` 참조) |
| **탬핑** | 강하게 | 저항↑ 속도↓. **압력을 빠르게 올릴수록 차이가 크고, 프리인퓨전을 길게 주면 영향이 미미해짐** |
| **탬핑** | curved · nutation | 가장자리만 저항↑ → 중앙 편추출 유도 |
| **탬퍼 지름** | 바스켓보다 작음 | 가장자리 저항↓. 빠른 승압에선 영향 미미, **긴 프리인퓨전에선 가장자리 편추출이 커질 수 있음** |
| **회전 디스트리뷰터** | 깊게 빼서 회전 | 원심력으로 가장자리 저항↑ → 중앙 편추출 유도 |
| **태핑** | 많이 | 가는 입자가 하단으로 내려감 → **최소 횟수로** |

**탬핑은 특별한 목적이 없으면 항상 일정하게 한다.**

**디스트리뷰션의 목적 3가지**: 뭉친 커피 풀기 / 분쇄도 분포 고르게 하기 / 베드 높이 일정하게 하기.
분쇄도 분포를 고르게 하는 데 **가장 효과가 좋은 것은 도징컵·쉐이커로 흔들어 섞는 것**이다. 싱글도징 그라인더처럼 분쇄 마지막에 미분 위주로 나오거나 토출구 좌우 편차가 있으면 쉐이킹이 특히 유효하다. (원문 16)

### 중앙 편추출

여러 변수(중앙 집중 바스켓·curved 탬핑·nutation·회전 디스트리뷰터)가 공통으로 유도한다.

- 편추출이므로 **수율↓**
- 다만 압력이 원형으로 고르게 퍼져 구조가 안정되므로 **일관성은 오히려 좋아진다**
- 퍽 가장자리가 밀집해 벽 역할 → 바스켓 내경을 줄이는 효과 → **전체 저항↑ → 속도↓ 시간↑**

"편추출 = 무조건 나쁨"으로 다루지 않는다. (원문 16)

## 미분

**미분량과 미분 분포는 별개 변수다.** 섞으면 저자 글이 모순처럼 보인다.

- **미분량** → 향미에 기여. 저자 실험에서 미분을 덜어내자 TDS는 0.04%, 시간은 3초밖에 안 변했는데 **관능은 "매우 큰 차이"로 톤이 어두워지고 산미가 줄고 베르가못 향이 사라졌다**. [검증, n=1] (원문 15)
- **미분 분포** → 흐름을 좌우. 아래로 내려가면(태핑·교반·스월링) 저항↑·클로깅↑, 위로 올라가면(블루밍) 저항 안정.

저자의 가설: 통념("미분=바디·단맛, 볼더=향미")이 뒤집혀 있고, **향미 성분은 저분자·경량이라 미분에서 많이 추출되고, 단맛·바디는 분쇄도가 아니라 도징량·농도가 결정한다.** [가설] (원문 15)

저자 스스로 신뢰도를 낮게 표시했다 — "한번의 결과이고 당연히 신뢰성은 매우 떨어질 테지만".

## 장비 유형에 따른 부호 반전

**같은 "저항 증가"가 장비에 따라 반대 결과를 낸다.** (원문 15)

- **정유량 프로파일(디센트 등)**: 저항↑ → 압력↑ → 오히려 **약간 빠름**
- **중력식 필터커피**: 저항↑ → **느려짐**
